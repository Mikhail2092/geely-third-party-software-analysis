# Профили автомобильных сигналов AutoService

В каталоге находятся 13 таблиц сопоставления сигналов, извлечённых без изменения из `assets` APK AutoService. Двенадцать профилей предназначены для Android Automotive VHAL, один профиль для KX11 2021 использует ECARX Car Signal.

## Назначение

AutoService выбирает таблицу по текущему источнику данных и профилю автомобиля. Каждая запись связывает единый идентификатор `propertyId`, используемый клиентами AutoService, с идентификатором сигнала конкретной автомобильной платформы. При чтении и записи сервис также применяет описанные в JSON преобразования значений.

Основной порядок обработки:

1. Выбирается источник VHAL, ECARX или имитационный источник.
2. Единый `propertyId` преобразуется в `readSignalId` или `writeSignalId` выбранного профиля.
3. Шаги `mapping` заменяют дискретные значения, а шаги `expression` выполняют числовое преобразование.
4. Полученное значение возвращается клиентам через единый интерфейс AutoService.

## Поля записей

- `propertyId` - единый идентификатор свойства AutoService.
- `readSignalId` и `readSignalName` - идентификатор и имя исходного сигнала для чтения.
- `writeSignalId` и `writeSignalName` - необязательные поля сигнала для записи. Их наличие означает, что запись предусмотрена данным профилем.
- `readTransform` - последовательность преобразований после чтения.
- `writeTransform` - последовательность преобразований перед записью.
- `steps` - упорядоченный список операций `mapping` или `expression`.

## Примечания

- Профили описывают прикладное сопоставление AutoService и не являются полным перечнем всех сигналов автомобиля.
- Одинаковый `propertyId` может ссылаться на разные системные идентификаторы в разных профилях.
- Профили VHAL используют системные идентификаторы свойств Vehicle HAL. Профиль ECARX использует идентификаторы службы Car Signal.
- Для проверки целостности все 13 файлов были разобраны как JSON после извлечения.
