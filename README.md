## Отчеты о статическом анализе / Static Analysis Reports

Материалы подготовлены исключительно методами статического анализа. APK не устанавливались и не запускались; динамическая отладка, подключение к автомобилю, выполнение Native-кода и сетевые запросы не выполнялись.

The materials were prepared exclusively through static analysis. The APKs were neither installed nor executed; no dynamic debugging, vehicle connection, native-code execution, or network requests were performed.

Отчеты описывают функции приложений, реализацию бизнес-процессов, локальные данные, интерфейсы, протоколы и подтверждаемые связи между компонентами проекта. Для каждого материала доступны русская и английская версии.

The reports cover application features, business-process implementation, local data, interfaces, protocols, and verifiable relationships between project components. Russian and English versions are available for every report.
